# Быстрый старт

## 1. Установка зависимостей

```bash
npm install
```

## 2. Запуск приложения

### Запуск всех микрофронтендов одной командой

```bash
npm run dev
```

Это запустит все 4 приложения параллельно:
- **root** (http://localhost:3000) - главное приложение
- **layout** (http://localhost:3001) - навигация
- **tasks** (http://localhost:3002) - задачи
- **order** (http://localhost:3003) - заказы

### Открытие приложения

После запуска всех приложений откройте в браузере:

**http://localhost:3000**

## 3. Навигация

В приложении доступны следующие разделы:

- **Home** (/) - главная страница
- **Tasks** (/tasks) - список задач из JSONPlaceholder API
- **Orders** (/order) - список заказов из JSONPlaceholder API

## 4. Остановка приложения

Нажмите `Ctrl+C` в терминале, где запущен `npm run dev`

## 5. Очистка

Для очистки всех dist папок:

```bash
npm run clean
```

## Troubleshooting

### Ошибка "Cannot GET /remoteEntry.js"

Убедитесь, что все remote приложения (layout, tasks, order) запущены перед открытием root приложения.

### Порты заняты

Если порты 3000-3003 заняты, остановите процессы, использующие эти порты:

```bash
# MacOS/Linux
lsof -ti:3000,3001,3002,3003 | xargs kill -9
```

### Ошибки TypeScript

Проверьте, что все зависимости установлены:

```bash
npm install
```

## Архитектура

Проект использует **Webpack Module Federation** для организации микрофронтенд архитектуры:

- **root** - host приложение, загружает все remote модули
- **layout** - remote с компонентами Header и Sidebar
- **tasks** - remote с роутами для задач
- **order** - remote с роутами для заказов
- **@farzoom/shared** - общий пакет с типами и API клиентом
